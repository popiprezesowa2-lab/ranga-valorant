# Valorant Rank Overlay – by Nathxn

Nakładka z rangą Valoranta do OBS: ranga, RR, wygrane/przegrane na streamie, +RR i K/D.

**Strona:** https://popiprezesowa2-lab.github.io/ranga-valorant/

1. Wejdź na stronę, wpisz nick, tag, region i swój klucz HenrikDev (darmowy: Discord HenrikDev → #get-a-key lub api.henrikdev.xyz/dashboard).
2. Skopiuj link i wklej w OBS: Źródło → Przeglądarka → URL. Rozmiar 420×100.

Dane: HenrikDev API. Projekt nie jest powiązany z Riot Games.
